Hold-out test set

20% of the listings, never used for training or tuning, scored exactly once with the selected model.

R² varies a lot between folds (about ±0.18), because a few very expensive cars dominate squared error. MAE and MAPE are the reliable numbers.

Test error by brand segment

How the predictions were made. Every listing is predicted by a model that never saw it: out-of-fold predictions for the training portion (5 refits on the cross-validation folds) and the final model for the hold-out test portion. The error shown for a filter therefore covers all listings and is close to, but not identical to, the headline test-set figure.

Limits. Asking prices from a single 2019 snapshot, not sale prices. Filters are bucketed, and the dataset itself is private: this page contains only aggregated counts and histograms, and combinations with fewer than listings are hidden.
